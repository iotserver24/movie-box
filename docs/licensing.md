## Why this is called source-available

The standard open-source definition permits commercial use and redistribution. The requested no-selling and no-advertising conditions restrict those freedoms. This project therefore uses a custom **source-available license**, not MIT, Apache, GPL, or an OSI-approved open-source license. A public repository can still be source-available without meeting that definition.
